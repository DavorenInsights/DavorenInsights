# Davoren Insights — Ready-to-upload website

This folder contains the complete static GitHub Pages website.

## Publish

1. Extract this ZIP.
2. Open the repository currently hosting Davoren Insights.
3. Upload everything **inside** `DavorenInsights-main` to the repository root, replacing matching files.
4. Commit the changes.
5. Confirm GitHub Pages still publishes from the same branch and root folder.

## Add countdown artwork

Place images in `images/ev-countdown/` using lowercase names such as:

- `day-49.png`
- `day-48.png`
- `day-47.png`

Add each day's content at the top of `countdown-data.js`. Full instructions are in `COUNTDOWN-UPDATE-GUIDE.md`.

The existing Signals and Strategic Briefs remain live under the Insights Archive.
