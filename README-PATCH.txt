DAY 37–41 PATCH
================

This patch adds the new countdown images and updates countdown-data.js.

Upload these into your GitHub repository:

1. Replace countdown-data.js in the repo root.
2. Upload the following image files into images/ev-countdown/:
   - day-37.png
   - day-38.png
   - day-39.png
   - day-40.png
   - day-41.png

After upload, Day 37 will become the latest countdown item automatically.

If GitHub Pages still shows the old version, wait 1-2 minutes and refresh with Ctrl+F5.
